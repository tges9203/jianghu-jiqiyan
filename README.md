# 山河照影錄

原創玄幻武俠長篇。奕嵐與裴綺微由青州玄錢案相識，逐步走進修行江湖，從探案、修行到彼此扶持的慢熱情感。

- 目前已公開第 1～108 章，分為《酒肆風波》《青州詭案》《劍問江湖》《西陵燈影》四卷。
- 擴寫校訂進度：第 22～100 章曾完成逐章擴寫；後續精修以內容品質及節奏為準。
- 單章篇幅不設硬性字數限制，一般參考 1,800～2,500 字，依故事需要增減。
- 全書規劃 1,765 章。
