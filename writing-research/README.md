# 創作研讀共享資料庫

本目錄為公開儲存庫的一部分，不存放私人資訊、原著全文或未公開的小說伏筆。

研讀任務：每次先讀本檔及 progress.md（若尚未存在則建立），依兩部作品各自實際進度接續合法原文。更新 progress.md 與 techniques.md，記錄來源、章號、理解程度、通用技巧、適用條件與反例。未讀不得標記已讀。不得照搬原著。

創作任務：每次先讀 progress.md 與 techniques.md，僅採用已充分理解且適合山河照影錄既有設定的技巧。無法讀取時如實說明，不捏造研究成果。小說正文與研究資料分離。

初始化時尚未核實完整研讀進度；由研讀任務依實際可驗證紀錄補入。

正式創作另須查閱 [全作創作核心與發布前檢核](../review-report.md)，遵循使用者確認的第十六項人物口語、機鋒與自然幽默規範及所有既有規則。
